### 👨‍💻 About Me

- 🎓 **Education:** B.Tech in Aerospace Engineering at VIT Bhopal University.
- ✈️ **Domain Focus:** Autonomous fixed-wing UAV systems, aerodynamic dynamics, 6-DOF flight simulation, and telemetry engines.
- 💻 **Software Engineering:** Building clean, object-oriented software architectures in **Java** and flight dynamics tools in **Python**.
- 🛠️ **Current Endeavors:**
