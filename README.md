### ⚡ Developer Profile & Focus

- 🎓 **Academic Base:** B.Tech in Aerospace Engineering, VIT Bhopal University.
- ✈️ **Engineering Domain:** Autonomous fixed-wing UAV design, flight stability simulation, and telemetry engines.
- 🛠️ **Systems & Code:** Building object-oriented software architectures in **Java** and flight dynamics tools in **Python**.
- 🚀 **Core Projects:**
  - `uav-telemetry-engine`: Multi-threaded Java engine for real-time UAV telemetry processing and flight envelope validation.
  - `6dof-flight-sim`: Python framework for 6-DOF crosswind landing trim solving and flight dynamics calculation.
